# 🏦 Loan Approval Prediction (Machine Learning Project)
## 📌Project Overview
The Loan Approval Prediction project aims to automate the process of loan approval using Machine Learning techniques. Based on applicant details such as income, credit history, employment status, and other factors, the model predicts whether a loan should be approved or not.

This project helps financial institutions make faster and more accurate decisions while reducing manual effort and bias.

![ML](https://github.com/rushikeshwalode06-cod/Loan-Approval-prediction/blob/main/Loan%20approval.png?raw=true)

## 🎯 Objective
 #### 1. Predict loan approval status (Approved / Not Approved)
 #### 2. Build a reliable classification model
 #### 3. Improve decision-making efficiency in loan processing

 ## 📂 Dataset Information
 The dataset contains applicant details such as:
 1. Gender
 2. Married
 3. ApplicantIncome
 4. LoanAmount
 5. Credit_History
 6. Loan_Status (Target Variable)
